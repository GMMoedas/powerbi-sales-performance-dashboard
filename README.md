# 📊 Sales Performance Dashboard | Power BI

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um Dashboard Interativo de Gestão de Vendas utilizando Power BI, com o objetivo de transformar dados comerciais em informações visuais que facilitem o acompanhamento de resultados e a tomada de decisões.

## 🎯 Objetivo

Analisar o desempenho comercial por meio de indicadores estratégicos, permitindo uma visão geral do faturamento, comportamento das vendas e desempenho dos produtos e unidades.

## 📈 Indicadores e Análises

- Faturamento total;
- Comissão;
- Ticket médio;
- Faturamento por loja/unidade;
- Distribuição por forma de pagamento;
- Evolução mensal das vendas;
- Desempenho por produto;
- Filtros interativos para segmentação dos dados.

## 🛠️ Ferramentas e Tecnologias

- **Power BI:** desenvolvimento e visualização do dashboard.
- **DAX:** criação de medidas e indicadores, caso aplicável.
- **Power Query:** tratamento e transformação dos dados, caso aplicável.
